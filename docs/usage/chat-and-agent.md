# 聊天与 Agent

## 助手、话题与项目

- 助手保存名称、系统提示词、首选模型和启用的 MCP/Skill。
- 话题保存消息历史、自动标题、摘要和消息分支关系。
- 项目绑定一个本地目录，并创建项目助手与 `.aio/` 配置。

项目不是目录副本。Agent 的文件、Git、LSP 和内置文件系统 MCP 工具直接作用于绑定目录，应在执行前确认项目路径。

## Agent 模式

| 模式 | 行为 |
| --- | --- |
| 对话 | 禁用 Agent 工具，作为普通聊天使用 |
| 普通 | 可使用工具，修改文件等操作按权限规则请求确认 |
| 自动 | 自主迭代执行，减少交互确认 |
| Plan | 调研需求并输出计划，不执行实际修改 |
| 工作流 | 将任务拆成工作流并自动执行 |

自动和工作流模式可能修改文件或运行命令。对不熟悉的仓库优先使用普通或 Plan 模式。

Agent 可使用文件、Shell、Git、联网搜索、LSP 诊断等内置工具，也可以调用项目启用的 MCP 工具。危险命令会经过额外检查；项目可在 `.aio/permissions.json` 中覆盖默认权限。

## 子智能体

AIO 内置代码探索、代码实现、通用、架构、诊断、审查、文档、测试和需求分析角色。每个角色有独立工具白名单/黑名单，且不能递归创建更多子智能体。

在“设置 → 子智能体模型”中可以：

- 为角色设置云模型覆盖；
- 创建自定义角色；
- 限制角色可用工具；
- 删除自定义角色。

## 附件

聊天输入支持：

- 图片：PNG、JPG、JPEG、WebP，单文件不超过 10 MiB；
- 文档：PDF、DOCX、PPTX，单文件不超过 30 MiB；
- 文本：TXT、MD、JSON、CSV、LOG、XML、YAML、YML、INI、TSV，单文件不超过 5 MiB。

图片会转换为数据 URI；PDF、Office 和文本文件会提取文本。附件按 SHA-256 去重保存在应用数据目录，删除关联消息、话题或助手时同步清理。

## 会话辅助功能

- 上下文压缩：使用 `/compact` 总结较早对话。
- 自动标题：首次消息后生成话题标题，失败时使用本地后备标题。
- 消息分支：从指定消息创建独立话题分支。
- Git 分支：项目聊天顶部可查看和切换仓库分支。
- LSP 诊断：项目语言服务器可自动检测，问题面板展示错误与警告。
- 用量统计：按时间范围和模型汇总输入、输出 Token。

## 斜杠命令

| 命令 | 作用 |
| --- | --- |
| `/clear` | 清空当前话题历史 |
| `/compact` | 压缩当前上下文 |
| `/review` | 审查代码变更 |
| `/explain` | 解释代码 |
| `/fix` | 修复指定问题 |
| `/optimize` | 优化代码 |
| `/translate` | 翻译为中文 |
| `/summarize` | 总结内容 |
| `/search` | 切换联网搜索 |
| `/settings` | 打开设置 |
| `/help` | 列出命令 |
| `/btw <问题>` | 基于当前上下文进行临时侧问 |

`/btw` 使用独立流式请求，不调用工具、不写入话题历史，也不会中断正在执行的主任务。

## 分享与导出

分享面板支持截图、Markdown、JSON 和 PDF。HTML 由导出工具生成并用于渲染；导出时可以选择是否包含推理、系统消息和工具调用。

MCP 和 Skill 的安装、绑定与审批规则见[MCP 与 Skill](mcp-and-skills.md)。
