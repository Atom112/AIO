# Agent 工具参考

## 概述

Agent 模式下提供 20+ 个内置工具，跨 6 个类别。以下总表列出所有工具及其基本权限特征：

> **执行语义**：同一响应块内的只读工具（读取/搜索/Web 查询/Git 读取/LSP/记忆检索）并发执行；变更类工具（文件写入、命令执行、Git 写）与 MCP 工具按原始顺序串行。可在应用配置中关闭（`parallelToolExecution`）。
>
> **主 Agent 工具集**：默认 hybrid——只读内置工具直达，变更操作委托子智能体（`mainAgentToolAccess`：hybrid / orchestrator / full）。
>
> **MCP 工具**：助手勾选的 MCP server 工具会注入 Agent 循环（general 子代理角色亦可用）；与其他工具重名时自动重命名为 `mcp__<server>__<tool>`。未信任 server 的工具在 Auto/Workflow 模式下仍逐次审批（MCP 设置中的「受信任」开关）。

## 文件工具

来源：`src-tauri/src/utils/file_tools.rs`

所有文件工具路径受项目根目录沙箱限制（`safe_path`），不可访问项目外文件。

### `read_file`

读取文件内容。

| 项目       | 值                                                                                                                                                                                                                        |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **描述**   | 读取项目目录内指定文件的内容，输出带 1-based 行号（格式 ` 1                                                                                                                                                               | 内容`，可直接用于 `replace_in_file`的`start_line`/`end_line`）。二进制文件会被拒绝。默认最多 300 行 / 32KB，超限返回头部+尾部并标注省略的行号区间。 |
| **参数**   | `path` (string, 必填) — 文件路径；`max_lines` (integer, 可选) — 最大行数，默认 300，传 -1 不限；`max_bytes` (integer, 可选) — 最大字节数，默认 32KB；`with_hash` (boolean, 可选) — 返回文件 SHA-256 摘要（hashline 协议） |
| **返回值** | 带行号的文件文本内容（with_hash=true 时附加 `[HASH sha256:…]`）                                                                                                                                                           |
| **限制**   | 硬上限 1MB                                                                                                                                                                                                                |
| **权限**   | 读操作：Normal/Allow, Auto/Allow, Plan/Allow                                                                                                                                                                              |

### `write_file`

创建或覆盖文件。

| 项目       | 值                                                                    |
| ---------- | --------------------------------------------------------------------- |
| **描述**   | 写入文件内容。不存在则创建，已存在则覆盖。父目录自动创建。            |
| **参数**   | `path` (string, 必填) — 文件路径；`content` (string, 必填) — 文件内容 |
| **返回值** | 写入确认及字节数                                                      |
| **限制**   | 最大 5MB                                                              |
| **权限**   | Normal/Ask, Auto/Allow, Plan/Deny                                     |

### `list_directory`

列出目录内容。

| 项目       | 值                                                       |
| ---------- | -------------------------------------------------------- |
| **描述**   | 列出指定目录的条目（文件和子目录），包含大小和类型图标。 |
| **参数**   | `path` (string, 可选) — 目录路径，默认项目根目录         |
| **返回值** | 目录内条目列表（最多 10,000 条）                         |
| **限制**   | 最多 10,000 条                                           |
| **权限**   | 读操作：Normal/Allow, Auto/Allow, Plan/Allow             |

### `search_files`

按 glob 模式搜索文件。

| 项目       | 值                                                                                             |
| ---------- | ---------------------------------------------------------------------------------------------- |
| **描述**   | 递归搜索匹配 glob 模式的文件。                                                                 |
| **参数**   | `pattern` (string, 必填) — glob 模式，如 `"src/**/*.ts"`；`basePath` (string, 可选) — 起始目录 |
| **返回值** | 匹配文件列表（最多 10,000 条）                                                                 |
| **限制**   | 最多 10,000 条                                                                                 |
| **权限**   | 读操作：Normal/Allow, Auto/Allow, Plan/Allow                                                   |

### `search_content`

在文件内容中搜索正则表达式。

| 项目       | 值                                                                            |
| ---------- | ----------------------------------------------------------------------------- |
| **描述**   | 按正则表达式搜索文件内容。每个匹配文件显示最多前 10 行匹配行。                |
| **参数**   | `pattern` (string, 必填) — 正则表达式；`path` (string, 可选) — 目标文件或目录 |
| **返回值** | 匹配结果：文件名、行号、行内容                                                |
| **限制**   | —                                                                             |
| **权限**   | 读操作：Normal/Allow, Auto/Allow, Plan/Allow                                  |

### `replace_in_file`

在文件中执行替换（精确匹配或行范围锚定）。

| 项目       | 值                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| ---------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **描述**   | 两种模式：1) `old_string` 精确替换（必须恰好出现一次）；2) 行范围锚定——`old_string` 留空并传 `start_line`/`end_line`（1-based），工具按当前文件内容取该行范围替换为 `new_string`，大段修改时无需回传整段旧代码（更省 token）；行号过期会报错，请重新 `read_file`。可选 `anchor_hash`（hashline 协议）：read_file(with_hash=true) 或上次写/替换返回的文件摘要，提供时先校验文件未被修改，防止按过期上下文误改。成功返回新的 `[HASH sha256:…]` 供链式使用。 |
| **参数**   | `path` (string, 必填) — 文件路径；`old_string` (string, 可选) — 要替换的原始字符串（必须精确匹配）；`new_string` (string, 必填) — 替换后的新字符串；`start_line`/`end_line` (integer, 可选) — 行范围锚定模式的起止行号；`anchor_hash` (string, 可选) — 文件 SHA-256 摘要（hashline 防漂移）                                                                                                                                                               |
| **返回值** | 替换确认及匹配行号                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| **限制**   | 替换后内容不超过 5MB；二进制文件不可替换                                                                                                                                                                                                                                                                                                                                                                                                                  |
| **权限**   | Normal/Ask, Auto/Allow, Plan/Deny                                                                                                                                                                                                                                                                                                                                                                                                                         |

### `delete_file`

删除文件。

| 项目       | 值                                           |
| ---------- | -------------------------------------------- |
| **描述**   | 删除指定文件。不能删除目录（使用系统命令）。 |
| **参数**   | `path` (string, 必填) — 文件路径             |
| **返回值** | 删除确认                                     |
| **限制**   | —                                            |
| **权限**   | Normal/Ask, Auto/Ask, Plan/Deny              |

### `make_directory`

创建目录。

| 项目       | 值                                   |
| ---------- | ------------------------------------ |
| **描述**   | 创建新目录。父目录不存在时自动创建。 |
| **参数**   | `path` (string, 必填) — 目录路径     |
| **返回值** | 创建确认                             |
| **限制**   | —                                    |
| **权限**   | Normal/Ask, Auto/Allow, Plan/Deny    |

## Git 工具

来源：`src-tauri/src/utils/git_tools.rs`

通过系统 `git` CLI 执行。所有调用使用参数数组（非 shell 字符串），杜绝注入风险。非 Git 目录的工具执行会返回友好错误。

### `git_status`

查看工作区和暂存区状态。

| 项目       | 值                                                                         |
| ---------- | -------------------------------------------------------------------------- |
| **描述**   | 以机器可读格式（`--porcelain=v2`）显示修改、暂存、未跟踪的文件及当前分支。 |
| **参数**   | 无                                                                         |
| **返回值** | git status 输出（最多 80KB）                                               |
| **权限**   | 读操作：各模式均为 Allow                                                   |

### `git_diff`

查看差异对比。

| 项目       | 值                                                                                  |
| ---------- | ----------------------------------------------------------------------------------- |
| **描述**   | 默认显示工作区未暂存的变更。设置 `staged=true` 查看已暂存的变更。                   |
| **参数**   | `staged` (boolean, 可选) — 是否查看已暂存；`path` (string, 可选) — 限定到文件或目录 |
| **返回值** | unified diff 输出（最多 80KB）                                                      |
| **权限**   | 读操作：各模式均为 Allow                                                            |

### `git_log`

查看提交历史。

| 项目       | 值                                                                                                                                                  |
| ---------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| **描述**   | 默认最近 10 条记录。                                                                                                                                |
| **参数**   | `count` (integer, 可选) — 显示条数，默认 10，最大 50；`path` (string, 可选) — 限定到文件或目录；`oneline` (boolean, 可选) — 简洁单行模式，默认 true |
| **返回值** | git log 输出（最多 80KB）                                                                                                                           |
| **权限**   | 读操作：各模式均为 Allow                                                                                                                            |

### `git_add`

暂存文件。

| 项目       | 值                                                                                                                |
| ---------- | ----------------------------------------------------------------------------------------------------------------- |
| **描述**   | 将文件添加到暂存区。可以指定文件列表或使用 `all=true` 暂存全部变更。                                              |
| **参数**   | `files` (string[], 可选) — 要暂存的文件路径列表；`all` (boolean, 可选) — 暂存所有变更（`git add -A`），默认 false |
| **返回值** | 暂存确认                                                                                                          |
| **权限**   | Normal/Ask, Auto/Allow, Plan/Deny                                                                                 |

### `git_commit`

创建提交。

| 项目       | 值                                             |
| ---------- | ---------------------------------------------- |
| **描述**   | 创建 Git 提交。暂存区为空时拒绝提交。          |
| **参数**   | `message` (string, 必填) — 提交信息，最大 10KB |
| **返回值** | 提交确认                                       |
| **权限**   | Normal/Ask, Auto/Allow, Plan/Deny              |

查看类型/文档信息。

列出文件符号。

## Web 工具

来源：`src-tauri/src/utils/web_tools.rs`

安全措施：HTTPS-only、内网 IP 屏蔽（SSRF 防护）、响应体大小限制、速率限制。

### `web_fetch`

获取网页内容。

| 项目       | 值                                                                                                         |
| ---------- | ---------------------------------------------------------------------------------------------------------- |
| **描述**   | 获取指定 URL 的网页内容，返回纯文本（HTML 标签已剥离）。仅支持 HTTPS。                                     |
| **参数**   | `url` (string, 必填) — 网页 URL（必须 `https://`）；`max_bytes` (integer, 可选) — 最大返回字节数，默认 1MB |
| **返回值** | 网页纯文本内容                                                                                             |
| **限制**   | 连接超时 5s，总超时 30s；仅 HTTPS；内网 IP 被屏蔽                                                          |
| **权限**   | Normal/Ask, Auto/Allow, Plan/Deny                                                                          |

### `web_search`

搜索网页。

| 项目       | 值                                                                                  |
| ---------- | ----------------------------------------------------------------------------------- |
| **描述**   | 通过 DuckDuckGo 搜索网页，返回结果摘要和链接。                                      |
| **参数**   | `query` (string, 必填) — 搜索关键词；`count` (integer, 可选) — 返回结果数量，默认 5 |
| **返回值** | 结果摘要 + 链接列表                                                                 |
| **限制**   | 3 秒限流间隔（同进程）；仅 HTTPS                                                    |
| **权限**   | Normal/Ask, Auto/Allow, Plan/Deny                                                   |

## 命令执行工具

来源：`src-tauri/src/utils/shell_tools.rs`

### `execute_command`

在项目目录中执行系统命令。

| 项目       | 值                                                                                                                                                                                        |
| ---------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **描述**   | 执行系统命令，返回 stdout、stderr 和退出码。                                                                                                                                              |
| **参数**   | `command` (string, 必填) — 命令字符串，如 `"cargo build"`；`description` (string, 可选) — 命令用途说明（仅审计日志）；`timeout` (integer, 可选) — 超时毫秒，默认 60,000ms，最大 300,000ms |
| **返回值** | stdout + stderr 输出（各最多 50KB）                                                                                                                                                       |
| **限制**   | 命令长度最大 4096 字符；禁止反引号/`$()` 命令替换；禁止高危命令（`sudo`、`rm -rf /`、`format` 等）；Windows Job Object 沙箱                                                               |

| **权限**   | Normal/Ask, Auto/Allow, Plan/Deny；子智能体中 general/debugger/tester 角色允许，其他禁止                                                                                                  |

## 编排工具

来源：`src-tauri/src/core/subagent.rs`、`src-tauri/src/utils/think.rs`、`src-tauri/src/utils/project_map.rs`

### `delegate_task`

创建单个子智能体执行子任务。

| 项目       | 值                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| ---------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **描述**   | 创建子智能体执行独立的子任务。子智能体拥有独立的 LLM 上下文窗口。                                                                                                                                                                                                                                                                                                                                                                         |
| **参数**   | `profile` (string, 必填) — 子智能体类型：`explorer` / `coder` / `general` / `architect` / `debugger` / `reviewer` / `writer` / `tester` / `requirements` 或自定义角色 ID；`task` (string, 必填) — 完整任务描述；`context_files` (string[], 可选) — 初始文件路径列表；`wait` (boolean, 可选) — 是否等待完成，默认 true；`isolation` (string, 可选) — 文件隔离方式 `worktree` / `shared`，详见[多智能体并行写入协调](#多智能体并行写入协调) |
| **返回值** | 子智能体工作总结（worktree 隔离时附带合并结果说明）                                                                                                                                                                                                                                                                                                                                                                                       |
| **权限**   | Normal/Ask, Auto/Allow, Plan/Ask                                                                                                                                                                                                                                                                                                                                                                                                          |

### `delegate_tasks`

批量创建多个子智能体并行执行。

| 项目       | 值                                                                                                                                                                                        |
| ---------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **描述**   | 在单次调用中并行创建多个子智能体（1–10 个）。总耗时约等于最慢的子任务。git 项目上写入类任务默认使用独立 worktree 隔离（见[多智能体并行写入协调](#多智能体并行写入协调)）。                |
| **参数**   | `context` (string, 可选) — 所有子任务共享的上下文信息；`tasks` (array, 必填, 1–10 项) — 子任务列表，每项含 `profile`、`task`、`context_files`、`isolation`（可选，`worktree` / `shared`） |
| **返回值** | 各子智能体工作总结（worktree 隔离时附带各自合并结果说明）                                                                                                                                 |
| **权限**   | Normal/Ask, Auto/Allow, Plan/Ask                                                                                                                                                          |

### `create_workflow`

创建按序执行的子智能体工作流。

| 项目       | 值                                                                                                             |
| ---------- | -------------------------------------------------------------------------------------------------------------- |

### 多智能体并行写入协调

多个智能体并行修改文件时，AIO 通过「worktree 物理隔离 + 共享模式文件锁」两层机制防冲突：

- **隔离模式**（设置 → 应用设置 → 并行写入隔离，`subagentIsolationMode`）：
  - **自动（默认）**：git 项目上被等待的写入类子任务（`delegate_task` `wait=true` 与 `delegate_tasks` 任务）自动获得独立 git worktree（位于项目同级 `<项目>.aio-wt/` 目录、分支 `aio/sub-<id>`、基于当前 HEAD），完成后提交到子分支并自动 `git merge` 回当前分支；非 git 项目、网络路径或创建失败时回退共享模式。
  - **始终独立工作区**：同上，但不支持时回退并注明。
  - **共享目录（仅文件锁）**：所有子任务直接写项目根目录。
- **合并**：Auto 模式自动合并；Normal 模式整批一次审批（列出分支、变更文件与 diff 摘要）。**冲突**时合并安全中止、工作区保留，结果报告冲突文件清单，应基于最新代码串行重做该任务或手动解决。
- **共享模式保护**：`write_file` / `replace_in_file` / `delete_file` / `make_directory` 按文件获取互斥锁（等待 120 秒超时报持有者）；文件被其他智能体修改过之后，`replace_in_file` 必须携带 `anchor_hash`、覆盖性 `write_file` 必须携带 `expect_hash`，不匹配会报错并要求重新读取——丢失更新被转换为可恢复的重读错误。
- **范围**：`wait=false` 后台子智能体与工作流步骤固定共享模式（文件锁仍生效）；worktree 基于主检出 HEAD，不包含主目录未提交的改动，需要基于未提交改动工作时请在任务上传 `isolation: "shared"`。
- **建议**：并行写入任务尽量按文件集分工；shell 命令与 git 写操作（`git_add` / `git_commit` / `checkout_branch`）写文件不经文件锁（与业界一致），关键文件优先让智能体用文件工具直接修改；worktree 任务运行期间避免在主检出切换分支——子任务合并时合入的是当时的当前分支。

## 记忆工具（项目级 RAG）

来源：`src-tauri/src/services/memory/tools.rs`

项目记忆启用后（`memoryEnabled` + 项目设置开关），Agent 获得六个记忆工具：`remember` / `recall` / `search_memory` / `update_memory` / `forget_memory` / `search_code`。事实持久化到 `{project_root}/.aio/memory/memory.sqlite`（向量 + FTS5 关键词混合检索，可选用重排二阶段精排）；旧版 `{project_root}/.aio/knowledge.json` 首次打开时自动迁移为事实（幂等）。检索结果按 token 预算自动注入系统提示词稳定前缀（index=1）。

### `remember`

保存项目级事实（写前向量查重，高相似时由 LLM 仲裁 merge / update / supersede）。

| 项目       | 值                                                                                                                                                                                                            |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **描述**   | 记住一条项目级事实（架构决策、代码约定、常用模式、重要发现），跨会话持久化，支持语义检索。                                                                                                                    |
| **参数**   | `key` (string, 可选) — 简短标识（用于去重）；`content` (string, 必填) — 事实内容；`category` (enum, 必填) — `"decision"` / `"pattern"` / `"convention"` / `"note"` / `"entity"` / `"architecture"` / `"task"` |
| **返回值** | 保存确认                                                                                                                                                                                                      |
| **限制**   | 每项目默认上限 2000 条有效事实，超出按 importance × 访问衰减归档最低分项（pinned 除外）                                                                                                                       |
| **权限**   | Normal/Allow, Auto/Allow, Plan/Deny                                                                                                                                                                           |

### `recall`

语义 + 关键词混合检索项目记忆。

| 项目       | 值                                                                          |
| ---------- | --------------------------------------------------------------------------- |
| **描述**   | 检索项目级记忆（向量 + FTS5 关键词混合，返回带相关度与类别的事实列表）。    |
| **参数**   | `query` (string, 必填) — 检索意图描述；`category` (string, 可选) — 类别过滤 |
| **返回值** | 带相关度的事实列表                                                          |
| **权限**   | Normal/Allow, Auto/Allow, Plan/Allow                                        |

其他记忆工具：`search_memory`（精细检索，支持 `k` 与最低相关度 `min_score`）、`update_memory`（按 id 订正）、`forget_memory`（归档软删除）、`search_code`（代码库语义检索，需先在记忆面板索引代码库）。子智能体可使用只读的 `recall` 与 `search_code`。启用或关闭均在项目设置 → 记忆面板中管理，也可导出/导入记忆 JSON。
