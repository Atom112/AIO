# Agent 工具参考

## 概述

Agent 模式下提供 20+ 个内置工具，跨 6 个类别。以下总表列出所有工具及其基本权限特征：

| 工具名            | 类别 | Normal 默认 | Auto 默认 | Plan 默认 |
| ----------------- | ---- | ----------- | --------- | --------- |
| `read_file`       | 文件 | Allow       | Allow     | Allow     |
| `write_file`      | 文件 | Ask         | Allow     | Deny      |
| `list_directory`  | 文件 | Allow       | Allow     | Allow     |
| `search_files`    | 文件 | Allow       | Allow     | Allow     |
| `search_content`  | 文件 | Allow       | Allow     | Allow     |
| `replace_in_file` | 文件 | Ask         | Allow     | Deny      |
| `delete_file`     | 文件 | Ask         | Ask       | Deny      |
| `make_directory`  | 文件 | Ask         | Allow     | Deny      |
| `git_status`      | Git  | Allow       | Allow     | Allow     |
| `git_diff`        | Git  | Allow       | Allow     | Allow     |
| `git_log`         | Git  | Allow       | Allow     | Allow     |
| `git_add`         | Git  | Ask         | Allow     | Deny      |
| `git_commit`      | Git  | Ask         | Allow     | Deny      |
| `read_lints`      | LSP  | Ask         | Allow     | Ask       |
| `lsp_definition`  | LSP  | Ask         | Allow     | Ask       |
| `lsp_references`  | LSP  | Ask         | Allow     | Ask       |
| `lsp_hover`       | LSP  | Ask         | Allow     | Ask       |
| `lsp_symbols`     | LSP  | Ask         | Allow     | Ask       |
| `web_fetch`       | Web  | Ask         | Allow     | Deny      |
| `web_search`      | Web  | Ask         | Allow     | Deny      |
| `execute_command` | 命令 | Ask         | Allow     | Deny      |
| `think`           | 编排 | Allow       | Allow     | Allow     |
| `project_map`     | 编排 | Allow       | Allow     | Allow     |
| `delegate_task`   | 编排 | Ask         | Allow     | Ask       |
| `delegate_tasks`  | 编排 | Ask         | Allow     | Ask       |
| `create_workflow` | 编排 | Ask         | Allow     | Ask       |
| `read_skill`      | 编排 | Allow       | Allow     | Allow     |
| `read_artifact`   | 编排 | Allow       | Allow     | Allow     |
| `remember`        | 知识 | Ask         | Allow     | Ask       |
| `recall`          | 知识 | Ask         | Allow     | Ask       |

> 权限具体受项目 `.aio/permissions.json` 自定义规则影响。Deny 规则始终优先于 Allow。详见[权限系统参考](../reference/permissions.md)。

## 文件工具

来源：`src-tauri/src/utils/file_tools.rs`

所有文件工具路径受项目根目录沙箱限制（`safe_path`），不可访问项目外文件。

### `read_file`

读取文件内容。

| 项目       | 值                                                                                                                                                                                                                        |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **描述**   | 读取项目目录内指定文件的内容。二进制文件会被拒绝。默认最多 300 行 / 32KB，超限返回头部+尾部并提示省略。                                                                                                                   |
| **参数**   | `path` (string, 必填) — 文件路径；`max_lines` (integer, 可选) — 最大行数，默认 300，传 -1 不限；`max_bytes` (integer, 可选) — 最大字节数，默认 32KB；`with_hash` (boolean, 可选) — 返回文件 SHA-256 摘要（hashline 协议） |
| **返回值** | 文件文本内容（with_hash=true 时附加 `[HASH sha256:…]`）                                                                                                                                                                   |
| **限制**   | 硬上限 1MB                                                                                                                                                                                                                |
| **权限**   | 读操作：Normal/Allow, Auto/Allow, Plan/Allow                                                                                                                                                                              |

### `write_file`

创建或覆盖文件。

| 项目       | 值                                                                    |
| ---------- | --------------------------------------------------------------------- |
| **描述**   | 写入文件内容。不存在则创建，已存在则覆盖。父目录自动创建。            |
| **参数**   | `path` (string, 必填) — 文件路径；`content` (string, 必填) — 文件内容 |
| **返回值** | 写入确认及字节数                                                      |
| **限制**   | 最大 5MB                                                              |
| **权限**   | Normal/Ask, Auto/Allow, Plan/Deny                                     |

### `list_directory`

列出目录内容。

| 项目       | 值                                                       |
| ---------- | -------------------------------------------------------- |
| **描述**   | 列出指定目录的条目（文件和子目录），包含大小和类型图标。 |
| **参数**   | `path` (string, 可选) — 目录路径，默认项目根目录         |
| **返回值** | 目录内条目列表（最多 10,000 条）                         |
| **限制**   | 最多 10,000 条                                           |
| **权限**   | 读操作：Normal/Allow, Auto/Allow, Plan/Allow             |

### `search_files`

按 glob 模式搜索文件。

| 项目       | 值                                                                                             |
| ---------- | ---------------------------------------------------------------------------------------------- |
| **描述**   | 递归搜索匹配 glob 模式的文件。                                                                 |
| **参数**   | `pattern` (string, 必填) — glob 模式，如 `"src/**/*.ts"`；`basePath` (string, 可选) — 起始目录 |
| **返回值** | 匹配文件列表（最多 10,000 条）                                                                 |
| **限制**   | 最多 10,000 条                                                                                 |
| **权限**   | 读操作：Normal/Allow, Auto/Allow, Plan/Allow                                                   |

### `search_content`

在文件内容中搜索正则表达式。

| 项目       | 值                                                                            |
| ---------- | ----------------------------------------------------------------------------- |
| **描述**   | 按正则表达式搜索文件内容。每个匹配文件显示最多前 10 行匹配行。                |
| **参数**   | `pattern` (string, 必填) — 正则表达式；`path` (string, 可选) — 目标文件或目录 |
| **返回值** | 匹配结果：文件名、行号、行内容                                                |
| **限制**   | —                                                                             |
| **权限**   | 读操作：Normal/Allow, Auto/Allow, Plan/Allow                                  |

### `replace_in_file`

在文件中执行替换（精确匹配或行范围锚定）。

| 项目       | 值                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| ---------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **描述**   | 两种模式：1) `old_string` 精确替换（必须恰好出现一次）；2) 行范围锚定——`old_string` 留空并传 `start_line`/`end_line`（1-based），工具按当前文件内容取该行范围替换为 `new_string`，大段修改时无需回传整段旧代码（更省 token）；行号过期会报错，请重新 `read_file`。可选 `anchor_hash`（hashline 协议）：read_file(with_hash=true) 或上次写/替换返回的文件摘要，提供时先校验文件未被修改，防止按过期上下文误改。成功返回新的 `[HASH sha256:…]` 供链式使用。 |
| **参数**   | `path` (string, 必填) — 文件路径；`old_string` (string, 可选) — 要替换的原始字符串（必须精确匹配）；`new_string` (string, 必填) — 替换后的新字符串；`start_line`/`end_line` (integer, 可选) — 行范围锚定模式的起止行号；`anchor_hash` (string, 可选) — 文件 SHA-256 摘要（hashline 防漂移）                                                                                                                                                               |
| **返回值** | 替换确认及匹配行号                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| **限制**   | 替换后内容不超过 5MB；二进制文件不可替换                                                                                                                                                                                                                                                                                                                                                                                                                  |
| **权限**   | Normal/Ask, Auto/Allow, Plan/Deny                                                                                                                                                                                                                                                                                                                                                                                                                         |

### `delete_file`

删除文件。

| 项目       | 值                                           |
| ---------- | -------------------------------------------- |
| **描述**   | 删除指定文件。不能删除目录（使用系统命令）。 |
| **参数**   | `path` (string, 必填) — 文件路径             |
| **返回值** | 删除确认                                     |
| **限制**   | —                                            |
| **权限**   | Normal/Ask, Auto/Ask, Plan/Deny              |

### `make_directory`

创建目录。

| 项目       | 值                                   |
| ---------- | ------------------------------------ |
| **描述**   | 创建新目录。父目录不存在时自动创建。 |
| **参数**   | `path` (string, 必填) — 目录路径     |
| **返回值** | 创建确认                             |
| **限制**   | —                                    |
| **权限**   | Normal/Ask, Auto/Allow, Plan/Deny    |

## Git 工具

来源：`src-tauri/src/utils/git_tools.rs`

通过系统 `git` CLI 执行。所有调用使用参数数组（非 shell 字符串），杜绝注入风险。非 Git 目录的工具执行会返回友好错误。

### `git_status`

查看工作区和暂存区状态。

| 项目       | 值                                                                         |
| ---------- | -------------------------------------------------------------------------- |
| **描述**   | 以机器可读格式（`--porcelain=v2`）显示修改、暂存、未跟踪的文件及当前分支。 |
| **参数**   | 无                                                                         |
| **返回值** | git status 输出（最多 80KB）                                               |
| **权限**   | 读操作：各模式均为 Allow                                                   |

### `git_diff`

查看差异对比。

| 项目       | 值                                                                                  |
| ---------- | ----------------------------------------------------------------------------------- |
| **描述**   | 默认显示工作区未暂存的变更。设置 `staged=true` 查看已暂存的变更。                   |
| **参数**   | `staged` (boolean, 可选) — 是否查看已暂存；`path` (string, 可选) — 限定到文件或目录 |
| **返回值** | unified diff 输出（最多 80KB）                                                      |
| **权限**   | 读操作：各模式均为 Allow                                                            |

### `git_log`

查看提交历史。

| 项目       | 值                                                                                                                                                  |
| ---------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| **描述**   | 默认最近 10 条记录。                                                                                                                                |
| **参数**   | `count` (integer, 可选) — 显示条数，默认 10，最大 50；`path` (string, 可选) — 限定到文件或目录；`oneline` (boolean, 可选) — 简洁单行模式，默认 true |
| **返回值** | git log 输出（最多 80KB）                                                                                                                           |
| **权限**   | 读操作：各模式均为 Allow                                                                                                                            |

### `git_add`

暂存文件。

| 项目       | 值                                                                                                                |
| ---------- | ----------------------------------------------------------------------------------------------------------------- |
| **描述**   | 将文件添加到暂存区。可以指定文件列表或使用 `all=true` 暂存全部变更。                                              |
| **参数**   | `files` (string[], 可选) — 要暂存的文件路径列表；`all` (boolean, 可选) — 暂存所有变更（`git add -A`），默认 false |
| **返回值** | 暂存确认                                                                                                          |
| **权限**   | Normal/Ask, Auto/Allow, Plan/Deny                                                                                 |

### `git_commit`

创建提交。

| 项目       | 值                                             |
| ---------- | ---------------------------------------------- |
| **描述**   | 创建 Git 提交。暂存区为空时拒绝提交。          |
| **参数**   | `message` (string, 必填) — 提交信息，最大 10KB |
| **返回值** | 提交确认                                       |
| **权限**   | Normal/Ask, Auto/Allow, Plan/Deny              |

## LSP 工具

来源：`src-tauri/src/utils/lsp_tools.rs`、`src-tauri/src/utils/lsp_agent_tools.rs`

需要项目中有对应文件类型的语言服务器正在运行。LSP 启动失败不影响其他工具使用。

### `read_lints`

读取 LSP 诊断信息。

| 项目       | 值                                                                                                                                                                 |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **描述**   | 读取项目中的 LSP 诊断（编译错误、类型错误、代码警告等）。                                                                                                          |
| **参数**   | `paths` (string[], 可选) — 文件路径列表，空则返回所有文件诊断；`severity` (enum, 可选) — 过滤级别：`"error"` / `"warning"` / `"info"` / `"hint"` / `"all"`（默认） |
| **返回值** | 分级诊断列表                                                                                                                                                       |
| **权限**   | Normal/Ask, Auto/Allow, Plan/Ask                                                                                                                                   |

### `lsp_definition`

跳转到符号定义。

| 项目       | 值                                                                                                                                            |
| ---------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| **描述**   | 跳转到指定位置的定义，返回定义所在的文件路径、行号和列号。                                                                                    |
| **参数**   | `path` (string, 必填) — 文件路径（相对项目根目录）；`line` (number, 必填) — 行号（从 0 开始）；`character` (number, 必填) — 列号（从 0 开始） |
| **返回值** | 定义位置（文件:行:列）                                                                                                                        |
| **权限**   | Normal/Ask, Auto/Allow, Plan/Ask                                                                                                              |

### `lsp_references`

查找符号引用。

| 项目       | 值                                                                                                                          |
| ---------- | --------------------------------------------------------------------------------------------------------------------------- |
| **描述**   | 查找指定符号的所有引用，返回引用位置列表。                                                                                  |
| **参数**   | `path` (string, 必填) — 文件路径；`line` (number, 必填) — 行号（从 0 开始）；`character` (number, 必填) — 列号（从 0 开始） |
| **返回值** | 引用位置列表                                                                                                                |
| **权限**   | Normal/Ask, Auto/Allow, Plan/Ask                                                                                            |

### `lsp_hover`

查看类型/文档信息。

| 项目       | 值                                                                                                                          |
| ---------- | --------------------------------------------------------------------------------------------------------------------------- |
| **描述**   | 查看指定位置的类型信息和文档注释。                                                                                          |
| **参数**   | `path` (string, 必填) — 文件路径；`line` (number, 必填) — 行号（从 0 开始）；`character` (number, 必填) — 列号（从 0 开始） |
| **返回值** | hover 提示内容                                                                                                              |
| **权限**   | Normal/Ask, Auto/Allow, Plan/Ask                                                                                            |

### `lsp_symbols`

列出文件符号。

| 项目       | 值                                                         |
| ---------- | ---------------------------------------------------------- |
| **描述**   | 列出文件中的所有符号（函数、类、变量等）及其位置。         |
| **参数**   | `path` (string, 必填) — 要查询的文件路径（相对项目根目录） |
| **返回值** | 符号列表（层级展开）                                       |
| **权限**   | Normal/Ask, Auto/Allow, Plan/Ask                           |

## Web 工具

来源：`src-tauri/src/utils/web_tools.rs`

安全措施：HTTPS-only、内网 IP 屏蔽（SSRF 防护）、响应体大小限制、速率限制。

### `web_fetch`

获取网页内容。

| 项目       | 值                                                                                                         |
| ---------- | ---------------------------------------------------------------------------------------------------------- |
| **描述**   | 获取指定 URL 的网页内容，返回纯文本（HTML 标签已剥离）。仅支持 HTTPS。                                     |
| **参数**   | `url` (string, 必填) — 网页 URL（必须 `https://`）；`max_bytes` (integer, 可选) — 最大返回字节数，默认 1MB |
| **返回值** | 网页纯文本内容                                                                                             |
| **限制**   | 连接超时 5s，总超时 30s；仅 HTTPS；内网 IP 被屏蔽                                                          |
| **权限**   | Normal/Ask, Auto/Allow, Plan/Deny                                                                          |

### `web_search`

搜索网页。

| 项目       | 值                                                                                  |
| ---------- | ----------------------------------------------------------------------------------- |
| **描述**   | 通过 DuckDuckGo 搜索网页，返回结果摘要和链接。                                      |
| **参数**   | `query` (string, 必填) — 搜索关键词；`count` (integer, 可选) — 返回结果数量，默认 5 |
| **返回值** | 结果摘要 + 链接列表                                                                 |
| **限制**   | 3 秒限流间隔（同进程）；仅 HTTPS                                                    |
| **权限**   | Normal/Ask, Auto/Allow, Plan/Deny                                                   |

## 命令执行工具

来源：`src-tauri/src/utils/shell_tools.rs`

### `execute_command`

在项目目录中执行系统命令。

| 项目       | 值                                                                                                                                                                                        |
| ---------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **描述**   | 执行系统命令，返回 stdout、stderr 和退出码。                                                                                                                                              |
| **参数**   | `command` (string, 必填) — 命令字符串，如 `"cargo build"`；`description` (string, 可选) — 命令用途说明（仅审计日志）；`timeout` (integer, 可选) — 超时毫秒，默认 60,000ms，最大 300,000ms |
| **返回值** | stdout + stderr 输出（各最多 50KB）                                                                                                                                                       |
| **限制**   | 命令长度最大 4096 字符；禁止反引号/`$()` 命令替换；禁止高危命令（`sudo`、`rm -rf /`、`format` 等）；Windows Job Object 沙箱                                                               |
| **安全**   | 危险命令检测（词法 token 分析），拒绝破坏性/安装/网络外泄/环境注入/fork bomb 等模式                                                                                                       |
| **权限**   | Normal/Ask, Auto/Allow, Plan/Deny；子智能体中 general/debugger/tester 角色允许，其他禁止                                                                                                  |

## 编排工具

来源：`src-tauri/src/core/subagent.rs`、`src-tauri/src/utils/think.rs`、`src-tauri/src/utils/project_map.rs`

### `delegate_task`

创建单个子智能体执行子任务。

| 项目       | 值                                                                                                                                                                                                                                                                                                                    |
| ---------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **描述**   | 创建子智能体执行独立的子任务。子智能体拥有独立的 LLM 上下文窗口。                                                                                                                                                                                                                                                     |
| **参数**   | `profile` (string, 必填) — 子智能体类型：`explorer` / `coder` / `general` / `architect` / `debugger` / `reviewer` / `writer` / `tester` / `requirements` 或自定义角色 ID；`task` (string, 必填) — 完整任务描述；`context_files` (string[], 可选) — 初始文件路径列表；`wait` (boolean, 可选) — 是否等待完成，默认 true |
| **返回值** | 子智能体工作总结                                                                                                                                                                                                                                                                                                      |
| **权限**   | Normal/Ask, Auto/Allow, Plan/Ask                                                                                                                                                                                                                                                                                      |

### `delegate_tasks`

批量创建多个子智能体并行执行。

| 项目       | 值                                                                                                                                            |
| ---------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| **描述**   | 在单次调用中并行创建多个子智能体（1–10 个）。总耗时约等于最慢的子任务。                                                                       |
| **参数**   | `context` (string, 可选) — 所有子任务共享的上下文信息；`tasks` (array, 必填, 1–10 项) — 子任务列表，每项含 `profile`、`task`、`context_files` |
| **返回值** | 各子智能体工作总结                                                                                                                            |
| **权限**   | Normal/Ask, Auto/Allow, Plan/Ask                                                                                                              |

### `create_workflow`

创建按序执行的子智能体工作流。

| 项目       | 值                                                                                                             |
| ---------- | -------------------------------------------------------------------------------------------------------------- |
| **描述**   | 创建按顺序执行的子智能体工作流。每步的输出自动传递到下一步。至少需要 2 个步骤。                                |
| **参数**   | `title` (string, 必填) — 工作流标题；`steps` (array, 必填, ≥2 项) — 步骤列表，每项含 `profile`、`name`、`task` |
| **返回值** | 各步骤工作总结                                                                                                 |
| **权限**   | Normal/Ask, Auto/Allow, Plan/Ask                                                                               |

### `read_skill`

按需读取已启用 Skill 的完整说明（token 效率：Agent 模式下仅注入技能目录，完整内容按需读取）。

| 项目       | 值                                                                                    |
| ---------- | ------------------------------------------------------------------------------------- |
| **描述**   | 读取一个已启用 Skill 的完整说明与使用指令。任务涉及某技能时先调用本工具获取完整内容。 |
| **参数**   | `name` (string, 必填) — 技能名称（如 `docx`、`xlsx`）                                 |
| **返回值** | 技能完整说明文本；未找到时返回可用技能列表                                            |
| **权限**   | 所有模式均为 Allow                                                                    |

### `read_artifact`

读取压缩时本地归档的历史档案（snapcompact 式：摘要失败时自动归档，细节按需恢复）。

| 项目       | 值                                                                                                                                       |
| ---------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| **描述**   | 读取早期对话的本地归档内容。压缩早期消息时若摘要生成失败，会自动归档到数据目录并插入 `[历史归档 #id]` 占位，需要细节时按 id 调用本工具。 |
| **参数**   | `artifact_id` (string, 必填) — 历史归档 ID                                                                                               |
| **返回值** | 归档内容（截断至约 30k 字符）                                                                                                            |
| **权限**   | 所有模式均为 Allow                                                                                                                       |

### `think`

记录结构化思考（no-op）。

| 项目       | 值                                                                   |
| ---------- | -------------------------------------------------------------------- |
| **描述**   | 记录结构化思考过程。无副作用，仅返回确认。用于 Plan 模式和编排场景。 |
| **参数**   | `thought` (string, 必填) — 思考内容                                  |
| **返回值** | 确认文本（含前 100 字符预览）                                        |
| **权限**   | 所有模式均为 Allow                                                   |

## 知识工具

来源：`src-tauri/src/utils/knowledge.rs`

知识数据持久化到 `{project_root}/.aio/knowledge.json`，每次 Agent 启动时自动注入系统提示词。

### `remember`

保存项目级知识。

| 项目       | 值                                                                                                                                                                       |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **描述**   | 记住一条项目级知识（架构决策、代码约定、常用模式），跨 session 持久化。                                                                                                  |
| **参数**   | `key` (string, 必填) — 简短标识（用于去重和检索）；`content` (string, 必填) — 知识内容；`category` (enum, 必填) — `"decision"` / `"pattern"` / `"convention"` / `"note"` |
| **返回值** | 保存确认                                                                                                                                                                 |
| **限制**   | 最多 50 条，超出时移除最早的条目                                                                                                                                         |
| **权限**   | Normal/Ask, Auto/Allow, Plan/Ask                                                                                                                                         |

### `recall`

检索项目级知识。

| 项目       | 值                                                                                                                                              |
| ---------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| **描述**   | 按关键词模糊匹配 `key` 和 `content`，可选按类别过滤。                                                                                           |
| **参数**   | `query` (string, 必填) — 搜索关键词（大小写不敏感）；`category` (enum, 可选) — 类别过滤：`"decision"` / `"pattern"` / `"convention"` / `"note"` |
| **返回值** | 匹配的知识条目列表                                                                                                                              |
| **权限**   | Normal/Ask, Auto/Allow, Plan/Ask                                                                                                                |
